## 文档维护约定

- README 提供项目定位、快速开始和主要入口；详细参数、协议及排障保留在专题文档。
- 接口、配置或行为变更时，同步更新使用说明及配套组件文档。
- 示例使用脱敏值，命令注明运行位置，代码块标明语言。
- 区分当前实现与后续计划，保持相对链接和文档索引有效。
